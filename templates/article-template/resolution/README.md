# Resolution loops

One file per disputed claim sent through the **bounded five-round resolution loop** (see [`docs/REVIEW_PROTOCOL.md`](../../../docs/REVIEW_PROTOCOL.md) §5).

| Dispute | Disputed claim | Status |
|---|---|---|
| [dispute-001](dispute-001-<slug>.md) | <one line> | <pending / accepted / withdrawn / standing-dissent> |

Each loop terminates in exactly one outcome: **critique accepted**, **critique withdrawn**, or **standing dissent**. A dispute that only apparatus can settle is routed to `../experiment.md`.
