# Tutor — Article 0001

The **recursive tutor** (manifesto Pillar IV): an explainer that meets the reader at their level *and* recurses into the cited references.

- [`index.md`](index.md) — three reading levels (non-specialist → adjacent-field scientist → specialist), followed by **key references explained**, so you can follow the chain of support rather than taking citations on faith.

In a live journal this would be an interactive agent answering follow-ups and expanding any cited source on demand. In this demonstration it is written Markdown — a static snapshot of what that agent would say.
